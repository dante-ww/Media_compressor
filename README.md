# Media Cruncher Express 🚀

**Media Cruncher Express** is a lightweight, user-friendly Windows desktop application designed to compress videos and images down to **under 10 MB** automatically. Perfect for sharing media on Discord (without Nitro), email, or messaging platforms!

---

## ✨ Key Features

* ⚡ **Target Compression:** Automatically calculates and applies optimal settings to keep output files under 10 MB.
* 🎯 **Drag & Drop:** Simple, intuitive interface—just drop your media file to start crunching.
* 🛠️ **Automated Dependencies:** Seamlessly downloads and configures FFmpeg on first run without manual setup.
* 🖼️ **Multi-Format Support:** Handles major video (.mp4, .mkv, .avi, .mov) and image (.jpg, .png, .webp) extensions.

---

## 📥 Download & Installation

1. Go to the **[Releases](../../releases)** section of this repository.
2. Download the latest `Install_MediaCruncher.exe`.
3. Run the installer and follow the setup wizard.
4. Launch **Media Cruncher Express** and crunch your media!

---

## Recommended Input Limits

To ensure optimal visual fidelity while crunching your media down to under 10MB:
* **Videos (.mp4, .mkv, .avi, .mov):** Up to **100 MB** for pristine quality (Maximum limit: **150 MB** for longer clips before noticeable quality drop).
* **Images (.jpg, .jpeg, .png, .webp):** Up to **50 MB** (Handles extreme high-resolution graphics easily at 75% quality retention).
